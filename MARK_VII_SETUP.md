# MARK VII runtime setup

Use Python 3.11 on Windows. Install `requirements.txt`, then install `requirements-optional.txt` only for enabled integrations. The native WPF client builds with the .NET 8 Desktop SDK (`dotnet build desktop/Jarvis.Desktop.Codex`). FFmpeg is a separate executable needed for media processing; `ffmpeg-python` is only its Python wrapper. Tesseract OCR is likewise a separate executable. Install it from a trusted package source, then expose `tesseract` on `PATH` or set `TESSERACT_PATH` to its executable. The runtime checks the executable before calling OCR.

Copy `.env.example` to `.env` and configure only the services you use. Routine text requests route to local Ollama first; genuinely complex debugging, architecture, strategy, and multi-stage reasoning route to NVIDIA Nemotron. Bounded fallback continues through the remaining configured providers when the selected provider fails. The supported local model is **`jarvis:latest`** at `OLLAMA_HOST` (default `http://127.0.0.1:11434`). Set `OLLAMA_MODEL=jarvis:latest` explicitly for reproducible deployments; `ollama list` should show it. `OLLAMA_MODELS` controls Ollama's storage location outside JARVIS; it does not change the API endpoint.

Image and screen understanding also route to local `jarvis:latest` first, with Gemini Vision as the configured cloud fallback. OCR is a separate Tesseract text-extraction path. A selected image or captured screen is sent to Gemini only after the local visual route fails and Gemini is configured; inspect sensitive images before invoking vision.

Status `LIVE` means a successful operation in the current runtime session, with a timestamp and expiry. A configured key, installed package, boot probe, or old registry record is weaker evidence. The browser microphone performs a single `/api/listen` request; continuous live voice has no accepted browser contract. Native UI numeric telemetry is only populated when the backend publishes it; unknown values remain unknown. The desktop's `DEV OVERRIDE` enables visual demo motion.

Run `python -m pytest -q tests`, `python -m compileall -q .`, and `dotnet build .\desktop\Jarvis.Desktop.Codex\Jarvis.Desktop.csproj --configuration Debug` after changes. Keep personal ledgers (`memory.json`, `tasks.json`, `status_registry.json`, identity enrollment, uploads, and personality data) out of publication and test fixtures. Live acceptance still requires Arju to check microphone/voice identity, audible TTS, face recognition, wake clap, Spotify, WhatsApp, Gmail, Calendar, and the visible WPF connection. Do not use those integrations for automated acceptance without an explicit user action.
