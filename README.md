J.A.R.V.I.S. MARK VIII operates under strict hardware boundary invariants tailored for workstation deployment:
* **Host Platform:** Windows 11 Home / Pro (x86_64, Python 3.11.x, .NET 8.0).
* **GPU Budget:** Dedicated NVIDIA GeForce RTX 3050 (6.0 GB VRAM).
* **Peak VRAM Ceiling:** $\le 5.0\text{ GB}$ peak VRAM under simultaneous vision, generative synthesis, and reasoning loads.
* **Single-GPU Tenancy:** All non-parametric exemplar retrieval, concept manifolds, graph traversals, and statistical process controls execute strictly on **CPU / NumPy / SciPy / SQLite / FAISS**.

## 🚀 Quick Start & Initialization

### 1. Prerequisites
* Python 3.11+
* .NET 8.0 SDK (for native WPF HUD)
* Windows 11 with NVIDIA GPU drivers (CUDA 12.x optional for local inference)

### 2. Environment Setup
```bash
# Clone repository
git clone https://github.com/CrixxLabs/J.A.R.V.I.S.git
cd J.A.R.V.I.S

# Install dependencies
pip install -r requirements.txt

# Verify cognitive status registry
python -c "import status_registry; print('Capabilities:', len(status_registry.get_registry().get_capabilities()))"
```

### 3. Launch Native HUD or CLI
```bash
# CLI interactive mode
python jarvis.py

# Launch Background Autonomous Daemon
python autonomous_daemon.py --run-all
```
